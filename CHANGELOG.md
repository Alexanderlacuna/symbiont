# CHANGELOG — symbiont

## v0.1.0 — 2026-11-10 · "the station lands"

The first version a stranger can run. Named by the tag `v0.1.0` on the publish commit.

- **package**: the code is an installable package named `symbiont` (was `harvester`); `pip install -e .`
  then `symbiont --help` works; one dependency, pinned (`PyYAML==6.0.3`); console door
  `symbiont` with `fetch · health · admit · manifest`, each delegating to the module that owns it.
- **tests**: `make check` runs the design's nine tests — T1 idempotency, T2 counts, T3 corruption,
  T4 projection (new: the arc tests, on a five-gene miniature provider served from 127.0.0.1),
  T5 budget, T6 licence-unknown, T7 staleness, T9 source-gone + quarantine + card; T8 (agent)
  is expected-fail, named in the output. Everything except T8 is offline.
- **fixture store**: `symbiont/fixtures/store` committed — a real miniature store (raw + state +
  xref + view + three run records incl. the zero-byte second run) a stranger reads before
  fetching anything; regenerated by `make fixtures-store`.
- **docs**: `symbiont/docs/` — OPS.md (backup, restore, size), OBS.md (heartbeat, the one command),
  PLUGIN-AUTHORING.md (the 4-call contract, the admission pipeline, sandbox, card, gate),
  POLICY-TEMPLATE.yml (numbers blank, fail-closed); DESIGN-STATION.md† is the design record.
  († held back from the public subset — a row in docs/WITHHELD.md, with the reason and how to request it.)
- **licence**: MIT for the code; per-source data terms table (MGI CC-BY 4.0 · Ensembl no
  restrictions · EuropePMC per-record) matching what the station records per run.
- **publish**: the code goes into this repository (which until now held documents only), tagged.

### known not-built (named, not hidden)
- T8 AGENT: an agent answering from tool output with every sentence mapping to an accession.
- T10 RETRIEVAL QUALITY: recall@k against the frozen public gold set (design §9b).
- the full-scale drop-and-rebuild of the 77k-row store's view (T4 is proved at miniature scale;
  the ship-run corruption test restores the real view to its baseline sha256).
- a schedule (cron/systemd is OPS.md's recipe; the station ships no daemon).
