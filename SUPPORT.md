# SUPPORT

Where to ask, and what is not supported.

```
BUG IN THE STATION        open an issue on THIS repository: github.com/Alexanderlacuna/symbiont
A SOURCE CHANGED SHAPE    the station refuses by name (REFUSED[schema-drift] / [count-mismatch]); open an issue with the run record
A FILE IS CITED BUT NOT HERE   docs/WITHHELD.md says why; if it is neither present nor listed, that is a defect — open an issue
DATA TERMS                 the station's code is MIT; the data carries each source's terms — see docs/SOURCE-TERMS.md
NOT SUPPORTED              running the station against a source whose licence cannot be read; storing data full-text where terms forbid it;
                           admitting a source that cannot state its own row count
```
